# Моє життя — економічний симулятор

Україномовна браузерна гра про роботу, особисті фінанси, побут і довгострокові цілі. Створена на чистих HTML, CSS та JavaScript без зовнішніх бібліотек.

## Ігрові системи

- **Робота й кар'єра:** робочі зміни, заробіток, навички, навчання та 5 професійних рівнів.
- **Особисті фінанси:** готівка, банківський рахунок, чистий капітал, заощадження, борг і екстрений кредит.
- **Інвестиції:** державні облігації, індексний фонд і стартап-фонд із різним ризиком; купівля/продаж активів, щоденні ринкові коливання та оцінка портфеля в чистому капіталі.
- **Додатковий дохід:** фриланс-проєкти з оплатою залежно від навичок; вони витрачають ігровий час та енергію.
- **Економіка:** щоденні відсотки на заощадження та борг, оренда кожні 7 ігрових днів, комунальні кожні 3 дні.
- **Потреби персонажа:** енергія, ситість, настрій і здоров'я.
- **Житло:** три покращення, що підвищують комфорт та відновлення.
- **Щоденні цілі:** робота, харчування та заощадження з грошовими бонусами.
- **Випадкові події:** бонуси, побутові витрати й позитивні події.
- **Прогрес:** фінансова подушка, кар'єрні цілі, історія операцій і графік капіталу.
- **PWA:** адаптивний інтерфейс, локальне збереження та кешування для офлайн-відкриття.

## Економічні правила прототипу

- Банківські заощадження: +0,2% на ігровий день.
- Борг: +0,4% на ігровий день.
- Оренда: ₴3 800 кожні 7 ігрових днів.
- Комунальні: ₴450 кожні 3 ігрові дні.
- Продукти: ₴250, кава: ₴75.
- Робоча зміна: 8 ігрових годин; зарплата залежить від навичок і кар'єрного рівня.

Це ігрова економіка, а не фінансова порада. Усі дані зберігаються локально у браузері.

## Публікація

GitHub Actions автоматично перевіряє JavaScript і маніфест та розгортає сайт на GitHub Pages після оновлень у `main`. Після успішного workflow гра доступна за адресою: https://xott69.github.io/Game/.

## Запуск

1. Відкрий сайт у Safari на iPhone.
2. Натисни **Поділитися → На початковий екран**, щоб додати гру як PWA.

Поточна версія не потребує сервера, облікового запису або платних API.
