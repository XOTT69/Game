# Затишна Гавань — PWA v2

Українська merge-гра про кафе біля моря.

## Можливості
- Об'єднання предметів: кава, випічка, квіти та рибні страви.
- Дошка 20 клітинок: вибір, переміщення й злиття.
- Замовлення з перевіркою потрібної кількості предметів.
- Монети, енергія, досвід і рівні.
- Енергія відновлюється з часом: +1 кожні 5 хвилин, максимум 30.
- Відновлення куточків гавані, сюжетні глави й декор.
- Збереження прогресу у браузері.
- PWA manifest, SVG-іконка й service worker для офлайн-кешування.

## Запуск на iPhone
1. Опублікуй репозиторій на HTTPS-хостингу, наприклад GitHub Pages.
2. Відкрий адресу в Safari.
3. Натисни «Поділитися» → «На початковий екран».

Це оригінальний прототип із власною назвою та CSS-ілюстраціями.
